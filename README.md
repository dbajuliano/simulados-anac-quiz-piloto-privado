### Observações sobre os gabaritos
Os gabaritos das fontes **não foram considerados como verdade absoluta**. Durante a revisão foram encontrados casos em que:
1. a alternativa indicada pela fonte não corresponde à resposta tecnicamente adequada;
2. a questão ou alternativa estava prejudicada por OCR;
3. havia erro de formulação da pergunta;
4. havia inconsistência de numeração no gabarito;
5. a questão precisava de interpretação técnica para determinar a resposta.

Por isso, o gabarito exibido pelo site deve ser considerado **em revisão**. A presença de uma questão nesta errata significa que houve uma alteração ou problema identificado, mas **a ausência da questão nesta lista não significa que ela esteja necessariamente validada**.

### Auditoria em andamento
A base possui centenas de questões. As correções acima representam apenas os problemas já identificados e tratados até esta versão. **Ainda não foi concluída uma auditoria semântica individual de todas as 711 questões.**

Questões que apresentem dúvida técnica, formulação antiga, simplificação excessiva ou possível erro de gabarito devem ser verificadas antes de serem utilizadas como referência definitiva para estudo.
